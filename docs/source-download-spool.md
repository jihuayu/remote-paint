# Source 私有下载目录生命周期

Source 在原 `chromium.launch` 上传入服务端创建的独占下载目录，保留原 `browser.newPage`、Page、context 和 cookie。目录以私有0700模式创建并持有原目录句柄；路径不进入Agent下载DTO或SDK。Native下载预算开关与桥接仍关闭。

浏览器关闭请求前停止新增本地读者；正常关闭顺序保留capture/frame先关闭，renderer崩溃时先关闭浏览器。等待原本地Playwright关闭及原ChildProcess的实际close事件、已登记的实际本地读者工作完成后，核对目录身份、删除自有目录、确认路径消失并关闭目录句柄。读者租约覆盖`download.path()`、真实文件句柄关闭及Artifact清理；句柄关闭失败为不可撤销的不确定状态。

本地进程回执通过固定Playwright1.64.1的in-process映射获取，核对同一原launch的downloadsPath及实际ChildProcess类型、活动PID，再登记close事件；不新增Browser/Page/context。驱动版本或形状变化、remote连接、缺失能力均失败关闭，没有以断连替代进程退出的fallback。关闭请求有独立30秒门槛；超时保留目录与失败状态，不能因此声称后台close工作已经结束。

未知启动、意外断连、关闭失败、目录丢失/改名/替换或读者句柄不确定均不返回成功清理收据；保留尚存在的目录，继续交由外层runtime处理。APFS在目录删除后的fstat链接数可能保持原值，因此不能以链接数作为跨平台删除证明。目录身份检查用于本服务的资源归属，不声称能抵御恶意同权限宿主对检查和删除系统调用之间的路径竞争。

本项不证明整个进程namespace已退出，不提供Chromium写入前额度或Playwright元数据物理上限；原下载输出合同及完整Native桥接验收保持待完成。

最终冻结1195文件候选的140个JS测试文件共1456项：macOS1441通过/15平台跳过，Linux1450通过/6平台跳过，21项新增边界两平台均实际通过。真实Linux Source探针使用独立旧浏览器工作副本，验证一次原launch/一次原Page、同一context与cookie、8003字节实际HTTP下载/分块/hash、legacy未arm下载残留归属及原进程关闭后的目录消失；5个已记录进程身份退役，探针容器删除。正式浏览器及采样器未运行或改写。

首轮开发41项有10项因APFS链接数假设失败；修正后通过。首次Linux完整回归两项因缺少可写artifacts目录失败；加挂载后同源通过。第二候选Linux容器在Mac尚未创建artifacts挂载点时启动失败125，测试未执行；最终候选预建空挂载点，代码只读、artifacts独立tmpfs，完整回归通过。所有失败、日志及候选均保留。

21项新增边界覆盖私有权限/原Page、未知启动、启动与关闭交错、意外断连/关闭失败、独立进程回执与30秒超时/迟到事件、真实FD读者等待、改名/替换/符号链接、幂等清理和真实legacy接线。原Native436项仅继承已有组件证据，本轮没有重编或重跑；新Native桥接/正常导航后的ticket退休收据/真实新浏览器、K6、41项和原失败8小时门槛仍待完成。
